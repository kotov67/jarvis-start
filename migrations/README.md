# Миграции

Разовые изменения настроек уже установленных помощников: то, что нельзя выразить
заменой файлов. Например, включить новую настройку OpenClaw или поправить расписание.

**Имя файла:** `<версия выпуска>-<коротко-что-делает>.sh`, например `1.2.0-enable-web-search.sh`.

**Когда запускается:** `update.sh` выполняет миграции, чья версия больше установленной
у клиента и не больше версии нового выпуска, по порядку версий. Новые установки
миграции не проходят: у них уже стоит актуальная версия.

**Правила для миграции:**

- запускается от пользователя jarvis через `bash`, `openclaw` и `npm` в PATH;
- должна быть **повторяемой**: второй запуск ничего не ломает (проверь, прежде чем менять);
- код выхода не 0 значит ошибку: обновление откатится из копии;
- если нужен перезапуск помощника, создай файл `"$JARVIS_UPDATE_RESTART_FLAG"`;
- переменные: `JARVIS_HOME_DIR` (~/jarvis-start), `JARVIS_WORKSPACE` (~/.openclaw/workspace),
  `JARVIS_FROM_VERSION`, `JARVIS_TO_VERSION`.
