# Джарви Старт

Свой ИИ-помощник на своём сервере за час. Пишете ему в Телеграм, он помнит вас,
ваши проекты и договорённости, работает круглосуточно и умеет делать, а не только
советовать.

Это набор из установочного скрипта и методички. Человек без опыта программирования
проходит путь от «купил сервер» до «переписываюсь с помощником» по шагам.

## Что получается в итоге

- помощник на вашем личном сервере, данные никуда не уходят
- общение в Телеграме через вашего собственного бота
- панель в браузере с адресом и паролем, ставится на телефон как приложение
- долгая память: помнит договорённости, ведёт дневник, напоминает
- мозг Claude по вашей подписке, без ключей API и без счётчика токенов
- на этом же сервере поднимается личный VPN, через который вы открываете Claude

## Быстрый старт

Полная инструкция с картинками: [SETUP.md](SETUP.md) и файл `Джарви-Старт.pdf`.
Коротко весь путь выглядит так.

**1. Купить сервер.** [По этой ссылке](https://ishosting.io/affiliate/NzU4MiM4),
тариф Start или Medium, система Ubuntu 24.04. Страна: Нидерланды, Германия,
Финляндия, Турция или Казахстан — **не Россия и не США**. В письме придут адрес
сервера и пароль. Сразу проверьте, что сервер отвечает: `nc -vz АДРЕС 22` на Mac
или `Test-NetConnection АДРЕС -Port 22` в PowerShell. До многих американских
дата-центров из России нет дороги, и это выяснится только на этом шаге.

**2. Поднять свой VPN на этом же сервере.** Приложение
[AmneziaVPN](https://amnezia.org): «Self-hosted VPN», вводите IP и пароль сервера,
установка автоматическая. Терминал не нужен, занимает пять минут. Без этого шага
сайт Claude из России не откроется.

**3. Оформить подписку Claude Pro.** Под ключ, вместе с почтой и оплатой:
[@claude_reg_bot](https://t.me/claude_reg_bot?start=r_48395647). Или самостоятельно, через виртуальную карту: как именно,
разобрано в методичке.

**4. Зайти на сервер.** На Windows через PowerShell, на Mac через Терминал:

```bash
ssh root@АДРЕС_СЕРВЕРА
```

**5. Одна команда, которая ставит всё:**

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/kotov67/jarvis-start/main/install.sh)
```

**6. Войти в подписку Claude** (ссылку скрипт покажет сам):

```bash
sudo -iu jarvis claude auth login
```

**7. Собрать помощника:**

```bash
sudo -iu jarvis /home/jarvis/jarvis-start/bin/setup.sh
```

Скрипт спросит имя помощника, ваш часовой пояс и токен Телеграм-бота, а в конце
выдаст адрес панели и пароль. После этого пишите боту в Телеграм.

## Если что-то сломалось

```bash
sudo -iu jarvis /home/jarvis/jarvis-start/bin/doctor.sh
```

Скрипт проверит семь основных мест и напишет по-русски, что именно чинить.

## Честные предупреждения

- Помощник получает права администратора на сервере. Это нужно, чтобы он мог
  работать сам. Держите на этом сервере только то, что не жалко ему доверить.
- Сервер берите за пределами России: изнутри страны Claude и Телеграм напрямую
  недоступны, понадобится прокси и всё усложнится втрое.
- Помощник умеет ошибаться. Не давайте ему доступ к деньгам и публикациям, пока
  не привыкнете к его манере работы.
