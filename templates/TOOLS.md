# TOOLS.md - Заметки по своему хозяйству

Навыки описывают, *как* работает инструмент. Этот файл про *твою* обстановку:
адреса серверов, имена устройств, логины сервисов, любимый голос озвучки,
названия комнат и камер. Всё, что уникально для этой установки.

## Сервер

- Помощник живёт на своём сервере, пользователь `{{AGENT_NAME}}` (в системе: jarvis)
- Панель: https://{{DOMAIN}}, пароль в файле `~/.jarvis-panel-password`
- Проверка здоровья: `~/jarvis-start/bin/doctor.sh`
- Перезапуск: `openclaw gateway restart`
